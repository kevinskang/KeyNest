# KeyNest 사용자 가이드

## 1. 개요

KeyNest는 GitHub Personal Token, OpenAI API Key 등 민감한 키와 토큰을 로컬에 안전하게 저장하고 관리하는 Windows 데스크톱 애플리케이션입니다.

- 인터넷 연결 없이 로컬에서만 동작합니다.
- 데이터는 `keynest.db` SQLite 파일에 AES-256-GCM으로 암호화되어 저장됩니다.
- 로그인 비밀번호는 bcrypt로 안전하게 해시되어 저장됩니다.

---

## 2. 시작하기

### 2.1 실행

1. `KeyNest.exe`를 실행합니다.
2. 처음 사용하는 경우 회원가입 화면에서 계정을 생성합니다.
3. 이미 계정이 있으면 로그인 화면에서 이메일과 비밀번호를 입력하고 로그인합니다.

### 2.2 회원가입

- 이메일: 로그인 ID로 사용합니다.
- 비밀번호: 최소 8자 이상 입력합니다.
- 비밀번호 확인: 동일한 값을 다시 입력합니다.

> 이메일 중복 등록은 허용되지 않습니다.

### 2.3 로그인

- 이메일과 비밀번호로 로그인합니다.
- 로그인 실패 시 화면에 오류 메시지가 표시됩니다.
- 앱을 종료하거나 로그아웃하면 세션이 해제됩니다.

---

## 3. 메인 화면 안내

메인 화면은 로그인 후 표시되며, 키 목록 관리와 검색을 할 수 있습니다.

### 3.1 헤더

- 앱 이름: `KeyNest`
- 버전 및 작성자: `v1.0.0 · KANGPOLE`
- 총 등록된 키 개수
- 로그아웃 버튼

### 3.2 검색 영역

- `Key Name 검색...`: 키 이름 부분 일치 검색을 수행합니다.
- 등록일 범위: 키 발급일 기준으로 From/To 날짜를 지정할 수 있습니다.
- 초기화 버튼: 검색 조건을 초기화합니다.
- 조회 버튼: 현재 조건으로 목록을 다시 로드합니다.
- `+ 키 등록` 버튼: 새 키 등록 모달을 엽니다.

### 3.3 자동 검색

- 검색 입력 또는 등록일 범위 변경 시 0.3초 후 자동으로 결과를 갱신합니다.
- 검색어와 날짜 범위는 함께 입력할 수 있으며, 둘 다 비어 있으면 전체 목록이 표시됩니다.

### 3.4 키 목록 테이블

표시되는 컬럼은 다음과 같습니다.

- Key Name
- Key Value
- URL
- 만료예정일
- 등록일
- 메모
- 액션 버튼

### 3.5 만료 임박 알림

로그인 후 앱은 오늘 기준 30일 이내에 만료되는 키를 자동으로 체크하고, 해당 키가 있으면 팝업으로 알립니다.

---

## 4. 키 등록

### 4.1 키 등록 방법

1. 메인 화면에서 `+ 키 등록` 버튼을 클릭합니다.
2. 새 키 등록 모달이 열리면 정보를 입력합니다.
3. 저장하면 목록이 자동으로 갱신됩니다.

### 4.2 등록 항목

- Key Name: 필수
- Key Value: 필수
- URL: 선택
- 만료예정일: 선택
- 등록일: 선택
- 메모: 선택

> Key Value는 화면에 마스킹 없이 실제 값이 표시됩니다.

---

## 5. 키 수정

1. 키 목록에서 수정 버튼을 클릭합니다.
2. 수정 모달에서 필요한 항목을 변경합니다.
3. 저장을 클릭하면 수정 내용이 반영되고 목록이 갱신됩니다.

---

## 6. 키 삭제

1. 키 목록에서 삭제 버튼을 클릭합니다.
2. 삭제 확인 다이얼로그에서 `확인`을 선택합니다.
3. 삭제된 데이터는 복구할 수 없습니다.

---

## 7. 키 복사

- 목록의 Copy 버튼을 클릭하면 해당 키 값이 클립보드에 복사됩니다.
- 복사 완료 시 알림 메시지가 표시됩니다.

---

## 8. 로그아웃

- 메인 화면 오른쪽 상단의 `로그아웃` 버튼을 클릭하면 로그인 화면으로 돌아갑니다.
- 로그아웃 시 암호화 키가 메모리에서 즉시 삭제됩니다.

---

## 9. 보안 정보

- 키 값은 데이터베이스에 암호화되어 저장됩니다.
- 로그인 비밀번호는 평문 저장되지 않습니다.
- 암호화 키는 비밀번호 기반 파생 키(PBKDF2-SHA256)로 생성됩니다.
- 앱 종료 또는 로그아웃 시 메모리 내 암호화 키를 초기화합니다.

---
