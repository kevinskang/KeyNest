# KeyNest - 요구사항 명세서

> 최초 작성: 2026-06-04  
> 최종 수정: 2026-06-04

---

## 1. 프로그램 개요

KeyNest는 개인이 사용하는 GitHub Personal Token, OpenAI API Key 등 다양한 키·토큰 정보를 로컬에 암호화하여 안전하게 관리하는 standalone 데스크톱 애플리케이션이다.

- **실행 환경:** Windows (standalone 실행 파일, 설치 불필요)
- **네트워크:** 인터넷 연결 불필요 (완전 로컬 동작)
- **데이터 저장:** 앱 실행 디렉토리의 `keynest.db` (SQLite3)

---

## 2. 사용자 관리

### 2.1 회원가입
- 앱 내 회원가입 화면을 통해 계정을 생성한다.
- 입력 항목: 이메일(ID), 비밀번호, 비밀번호 확인
- 이메일은 유효한 형식이어야 하며, 중복 등록을 허용하지 않는다.
- 비밀번호 정책: 최소 8자 이상
- 비밀번호는 bcrypt(cost=12)로 해시 후 저장한다. 평문은 DB에 저장하지 않는다.

### 2.2 로그인
- 로그인 화면에서 이메일(ID)과 비밀번호를 입력하여 인증한다.
- 로그인 성공 시 메인 화면으로 이동한다.
- 로그인 실패 시 오류 메시지를 표시한다. (계정 잠금 기능 없음)
- 앱 재시작 시 세션을 유지하지 않으며, 매번 로그인이 필요하다.
- 비밀번호 찾기/변경 기능은 v1 범위에서 제외한다.

### 2.3 로그아웃
- 메인 화면에서 로그아웃 버튼으로 로그인 화면으로 돌아간다.
- 로그아웃 시 메모리에 보관 중인 암호화 키를 즉시 초기화한다.

---

## 3. 만료 임박 알림

- 로그인 성공 직후, **만료예정일이 오늘로부터 30일 이내**인 키를 조회한다.
- 해당 키가 1개 이상 존재하면 팝업 모달로 목록을 표시한다.
- 모달에는 Key Name과 만료예정일이 표시된다.
- 이미 만료된 키(오늘보다 이전)도 함께 포함한다.
- 사용자가 모달을 닫으면 메인 화면으로 진입한다.

---

## 4. 메인 화면 (키 목록)

### 4.1 화면 구성
- 상단: 검색 영역 (Key명 입력, 등록일 범위 From/To)
- 중단: 키 목록 테이블
- 우측 상단: 등록(+) 버튼, Refresh 버튼, 로그아웃 버튼

### 4.2 키 목록 테이블 표시 컬럼

| 컬럼 | 표시 내용 | 비고 |
|------|-----------|------|
| # | 행 번호 | |
| Key Name | 키 식별 이름 | |
| Key Value | 복호화된 실제 키값 | 마스킹 없이 전체 표시 |
| URL | 관련 서비스 URL | |
| 만료예정일 | YYYY-MM-DD | 만료 임박/만료됨 시각적 표시 |
| 등록일 | 키 발급일 (사용자 입력값) | YYYY-MM-DD |
| 메모 | 메모 내용 | |
| 액션 | Copy / 수정 / 삭제 버튼 | |

- **정렬 기준:** DB 등록 일시(created_at) 최신순 (기본값)
- **만료 상태 시각화:** 만료됨(빨간색), 30일 이내 임박(주황색), 정상(기본색)

### 4.3 자동 검색
- 검색 필드에 값을 입력하면 **0.3초 debounce 후 자동으로 검색 결과를 갱신**한다.
- 검색 버튼 없이 실시간으로 동작한다.

### 4.4 검색 조건
- **Key명:** 입력값을 포함하는 Key Name 부분 일치 검색 (LIKE)
- **등록일 범위:** From 날짜 ~ To 날짜 사이에 등록(키 발급일)된 키 검색
- 두 조건은 **OR** 조건으로 처리한다.
- 모든 검색 조건이 비어있으면 전체 키를 조회한다.

### 4.5 Refresh
- Refresh 버튼 클릭 시 현재 검색 조건을 유지하며 목록을 다시 불러온다.

---

## 5. 키 등록

- 등록 버튼 클릭 시 등록 모달이 열린다.
- 등록 완료 후 목록이 자동으로 갱신(refresh)된다.

### 5.1 입력 항목

| 항목 | 필수 여부 | 설명 |
|------|-----------|------|
| Key Name | **필수** | 키 식별 이름. 동일 사용자 내 중복 허용 |
| Key Value | **필수** | 실제 키·토큰 값. 길이 제한 없음 |
| URL | 선택 | 관련 서비스 URL |
| 만료예정일 | 선택 | 키 만료 예정 날짜 (YYYY-MM-DD) |
| 등록일 | 선택 | 키 최초 발급일. 사용자 직접 입력 (YYYY-MM-DD) |
| 메모 | 선택 | 자유 텍스트 메모 |

---

## 6. 키 수정

- 목록의 각 행에서 수정 버튼 클릭 시 수정 모달이 열린다.
- 기존 입력 항목과 동일한 필드를 수정할 수 있다.
- Key Value 수정 시 새 값으로 재암호화하여 저장한다.
- 수정 완료 후 목록이 자동으로 갱신된다.

---

## 7. 키 삭제

- 목록의 각 행에서 삭제 버튼 클릭 시 확인 다이얼로그를 표시한다.
- 사용자가 확인하면 해당 키를 삭제하고 목록을 갱신한다.
- 삭제된 데이터는 복구할 수 없다.

---

## 8. 복사 기능

- 목록의 각 행에서 Copy 버튼 클릭 시 해당 키의 복호화된 실제 값을 클립보드에 복사한다.
- 복사 완료 시 간단한 피드백(예: "복사됨" 토스트)을 표시한다.

---

## 9. 보안 요구사항

- 화면에 표시되는 Key·Token 값은 **마스킹 없이 실제 값을 표시**한다.
- DB에 저장 시 키값은 **AES-256-GCM**으로 암호화한다.
- 암호화 키는 사용자 비밀번호에서 **PBKDF2-SHA256(100,000회)**로 파생한다.
- 암호화 키는 로그인 세션 동안 **메모리에만** 보관하며, 디스크에 저장하지 않는다.
- 로그아웃 또는 앱 종료 시 메모리의 암호화 키를 초기화한다.

---

## 10. 프로그램 구성

- **Frontend:** Vue 3 + TypeScript (Vite 빌드)
- **Backend:** Go 1.23
- **프레임워크:** Wails v2 (단일 실행 파일로 패키징)
- **데이터베이스:** SQLite3 (`mattn/go-sqlite3`)
- **상태 관리:** Pinia
- **라우터:** Vue Router 4
