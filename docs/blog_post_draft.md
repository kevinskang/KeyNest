# [개발자 필수템] 텍스트 파일에 적어둔 API Key는 이제 그만! 로컬 암호화 키 관리 프로그램 'KeyNest' 소개

안녕하세요! 
IT 분야에서 개발을 하거나 다양한 API 서비스를 사용하다 보면 GitHub Personal Access Token, OpenAI API Key, AWS Access Key 등 정말 수많은 **API 키와 토큰**을 다루게 됩니다.

이 많은 키들을 어떻게 보관하고 계시나요?
* 대충 메모장(.txt)에 적어둔다? 📂 (보안 취약!)
* 클라우드 메모장에 저장한다? ☁️ (인터넷 유출 걱정!)

이런 불안함을 해결하고, 내 PC 내부에서 완전 오프라인으로 안전하게 키를 암호화해 보관할 수 있는 **Windows 데스크톱 앱 'KeyNest'**를 소개합니다! ✨

---

## 🔒 KeyNest의 개발 목적

KeyNest는 **"완벽한 오프라인 환경에서 나만의 민감한 키와 토큰을 안전하게 보관하는 것"**을 목적으로 개발되었습니다. 
클라우드나 외부 서버에 데이터를 일절 전송하지 않기 때문에, 해킹이나 외부 유출 우려로부터 완전히 자유로운 Windows 전용 단일 실행(Standalone) 앱입니다.

---

## 💡 KeyNest의 핵심 기능 & 프로그램 구성

### 1️⃣ 보안 로그인 및 암호화 잠금
* **로컬 로그인 지원**: 나만의 마스터 비밀번호로 데이터를 안전하게 잠그고 해제합니다.
* **메모리 보안**: 로그아웃을 하거나 프로그램을 종료하면, 메모리에 임시 보관 중이던 암호키가 즉시 완전히 초기화되어 물리적인 데이터 탈취 위험을 차단합니다.

### 2️⃣ 편리한 API 키 등록 및 상세 관리
* 키 이름, 키 값, 관련 URL, 만료예정일, 키 발급일, 메모 등 필요한 정보를 한눈에 볼 수 있도록 구성되어 있습니다.
* 직관적인 테이블 화면을 통해 언제든지 키를 등록/수정/삭제할 수 있습니다.

### 3️⃣ 원클릭 클립보드 복사 (Copy)
* 키 값을 번거롭게 드래그해서 복사할 필요 없이, 목록에서 **[Copy]** 버튼 한 번만 누르면 클립보드에 바로 복사되어 작업 생산성을 극대화합니다.

### 4️⃣ 스마트 자동 검색 및 필터링
* 키 이름 검색 기능과 함께 키 발급일 기준 날짜 범위 검색을 지원합니다.
* 검색 조건을 변경하면 약 0.3초 후 자동으로 목록이 갱신되어 빠르고 편리하게 원하는 키를 찾을 수 있습니다.

### 5️⃣ 만료 임박 키 알림 서비스 (D-Day 케어)
* 만료 예정일을 등록한 키가 있는 경우, 로그인 시 **오늘로부터 30일 이내에 만료되는 키**들을 감지해 팝업으로 알려줍니다. 
* 키 만료로 인해 갑자기 서비스가 중단되는 곤란한 상황을 사전에 예방할 수 있습니다.

## 🛠️ 철저하게 검증된 안전한 로컬 보관

KeyNest의 모든 데이터는 프로그램 실행 폴더 내에 로컬 데이터베이스(`keynest.db`) 파일로 저장됩니다. 저장 시 **강력한 업계 표준 암호화 기술(AES-256)**로 암호화되므로, 혹시나 데이터베이스 파일 자체가 유출되더라도 마스터 비밀번호 없이는 내용을 절대로 열어볼 수 없습니다.
